# 价格考虑
通常圈子有两种模式，一种高价人少，一种价低人多。
需要先想清楚做用户深度运营的目标是什么，并作出判断。

* 50 元/年，可能能找到 5w 甚至更多人进来，社区运营的工作会复杂一些，但管理得当，可能能从一些用户比较「初阶」就培育起；
* 每年 999 甚至更高，会挡住大部分学生、收入略低的人，这样圈内活跃度前期或许不那么高，但质量应该很不错。

我其实倾向前者。

# 运营建议
小密圈是社区，也就是说，在这个社区里：

* 明确圈主、管理员、嘉宾身份；
* 明确圈子的规则（是否圈主和嘉宾说话为主，还是鼓励大家发言——建议鼓励发言）；
* 考虑一些活动（甚至可以拉企业支付奖品，做一些有奖活动——对企业可能也是非常好的回馈）。

在运营上，您应该有非常丰富的经验，我就不班门弄斧了。
