看到「聊天宝」做了微信聊天、微信朋友圈、微信公众号、趣头条、今日头条、拼多多的功能合集，我想起了 Unix 哲学。

Wikipedia 上 Unix 哲学（https://zh.wikipedia.org/wiki/Unix%E5%93%B2%E5%AD%A6）有好多种说法，我最认可的还是发明管道命令的 Doug McIlroy 总结的：

1. 做好一件事；
2. 让程序可以协同工作；
3. 让程序处理文本数据流，因为这是通用接口。

英文原文是：

1. Write programs that do one thing and do it well.
2. Write programs to work together.
3. Write programs to handle text streams, because that is a universal interface.

阮一峰也写了篇文章说起 Unix 哲学（http://www.ruanyifeng.com/blog/2009/06/unix_philosophy.html），他发现所有人都同意，"简单原则"----尽量用简单的方法解决问题----是"Unix哲学"的根本原则。这也就是著名的KISS（keep it simple, stupid），意思是"保持简单和笨拙"。
