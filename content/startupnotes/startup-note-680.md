第一条推的作者是 https://www.tiny.com/ 的创始人，按理说话也不会太不靠谱，他说了听到的小道消息：

埃隆·马斯克解雇了 Twitter 的 6,500 名员工，只剩下：2 位设计师、6 位 iOS 开发者、20 位网页开发者和大约 1,400 名销售和运营人员。

第二条推说这一年 X 的成绩单，写得长且混乱，我挑几条：
- 每天约有 5 亿篇帖子。
- 约有 5.5 亿月活跃用户。
- 每天有 150 万新注册用户（比去年增长了4%）。
- 用户时长增加 1扩展了网络骨干的容量和冗余性，每年节省了1390万美元。4%。
- 百分之九十的前 100 大广告商重返。

第三条推是 X 的工程团队，算官方信息，我也挑几条：
- 重构“为您推荐”的服务和排名系统，代码行数减少了 90%，从 70 万行减少到了 7 万行，计算占用减少了 50%，每个请求评分的帖子的吞吐量增加了 80%。
- 重构了 API 中间件层，删除了超过 10 万行代码和数千个未使用的内部端点，并消除了未被采纳的客户端服务，简化了架构。
- 将帖子元数据源的延迟减少了 50%，全球 API 超时错误减少了 90%。
- 以比 2022 年高出 37% 以上的速度阻止了机器人和内容爬虫，将私信垃圾信息减少了 95%。
- 关闭了萨克拉门托数据中心，并重新配置了 5200 个机架和 148000 台服务器，每年为公司节省了超过1亿美元。
- 优化了对云服务提供商的使用，并开始在本地进行更多操作。这种转变使我们的月度云成本减少了 60%。我们所做的变更中包括将所有媒体/大对象工件移出云端，这减少了我们整体云数据存储大小的 60%，另外，我们成功地将云数据处理成本减少了 75%。
- 扩展了网络骨干的容量和冗余性，每年节省了 1390 万美元。
