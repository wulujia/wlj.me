提醒一下创业的朋友看看 http://www.cac.gov.cn/2018-11/20/c_1123740989.htm。

内容安全问题，是互联网信息服务产品的最大风险。此前做网络安全技术工作的时候，经常会感叹安全人员工作难做——安全做好了，不会出问题。可是不出问题，老板不重视，甚至觉得安全岗位不重要。

没出过问题时，我们自己觉得无论内容安全还是网络安全，都做了不少工作，应该没问题。但出过事，再仔细回顾，会发现其实要做好，真的难，还是脑子里得有这根弦，多提醒下自己和同事们：

安全无小事。

从评估规定里摘抄了几条——估计有一定用户规模的互联网产品，都需要做一下：

第二条 本规定所称具有舆论属性或社会动员能力的互联网信息服务，包括下列情形：

```
（一）开办论坛、博客、微博客、聊天室、通讯群组、公众账号、短视频、网络直播、信息分享、小程序等信息服务或者附设相应功能；
```

```
（二）开办提供公众舆论表达渠道或者具有发动社会公众从事特定活动能力的其他互联网信息服务。
```
