Claude Code 让我工作舒服的核心原因：它和我的本地文件、文件夹一起工作。不是在一个独立的聊天窗口里空谈，而是直接操作我真实的工作环境。上下文是活的，不需要我复制粘贴来回搬运。
类比到知识星球：如果星主能和他的星球内容、和他的用户、和他的朋友们一起工作呢？

我和 AI 请教：Claude Code 的哪些设计，让一起工作感觉舒服？AI 的答复是：

- 共享上下文，不搬运：直接读你的文件，不需要复制粘贴。你说"改那个文件"，它知道是哪个。消除最大摩擦。
- 操作是真实的，不是建议：不说"你可以这样改"，直接改了给你看 diff。输出是动作，不是建议。交互从对话变协作。
- 权限边界清晰：改文件前问确认，危险操作需审批。信任感来自"我随时能拦住"，不是完全自动化。
- 上下文是持续的：记得之前干了什么、你的偏好、项目状态。不用每次重新交代背景。
- 和工具链在一起：能跑 shell、用 git、调 API，活在你的工作环境里，不是隔离沙箱。
- 粒度可控：可以给大任务让它拆解，也可以一步步精确指挥。适应不同控制欲。
