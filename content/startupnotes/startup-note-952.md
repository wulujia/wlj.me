最近开始觉得扛不动 16 寸 Macbook Pro 到处跑了，考虑还是回归手机操作。目前对 AI（以 Claude Code 为例）的控制，使用到的工具是：

- Mac：始终放在一个有可靠网络的地方，保持开机，当服务器使用
- Github：所有内容分项目上到 Github 保存，方便跨设备以及 Claude Code 的云端环境使用
- Terminal + tmux：Terminal 可选工具很多，tmux 主要是用于远程访问时，如果网络不稳定，不至于丢内容
- 移动设备：装上 Claude 客户端，可以控制远程 Mac 上的 Claude Code
