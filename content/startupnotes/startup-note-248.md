有朋友给我看了一位产品经理评价知识星球：不知道他们在瞎忙什么，几年了，产品看起来就一点都没有变化。

我回复：好产品就是这样的啊，哈哈。

其实这不是开玩笑，我还真是这么认为的。

举个桌面操作系统的例子，苹果的 MacOS 和微软的 Windows。

从我接触 MacOS 至今，其实它变化极大，但是在系统外观、操作体验、应用交互上几乎没有什么大的调整。

Windows 不一样，大版本之间的变革特别激进，比如 Windows8 直接取消了开始菜单——我至今还记得第一次装完 Windows8 之后我的茫然和手足无措——作为一个装机无数，玩过好多种桌面系统，甚至被同事戏称为「装机小王子」的准行家，居然装完 Windows 后五分钟还不知道该怎么用……
