# Reading 页面规范

状态：实施中。创建日期：2026-11-02。

## 范围

规范覆盖 `static/reading/` 下全部 HTML 页面。
专题中的子页使用同一规范。
`/reading/` 列表继续使用站点的 Hugo 模板。

## 阅读界面

- 使用系统无衬线字体。代码使用系统等宽字体。
- 正文为 16px，中文行高为 1.8。
- 正文栏最大宽度为 720px。
- 桌面目录宽度为 220px，位于正文左侧。
- 手机使用单栏，目录使用可折叠的 `details`。
- 页面包含返回 `/reading/` 的入口。
- 页面包含跳到正文的键盘导航入口。
- 标题、链接、表格和提示框使用统一样式。
- 图表保留必要的语义色，不能只靠颜色表达。

颜色采用现有绿色模板的配色。
亮色背景为 `#f5f8f7`，正文为 `#192b26`。
亮色表面为 `#ffffff`，主题色为 `#236b52`。
暗色沿用模板的深灰背景和浅色文字。
正文和说明文字的对比度至少为 4.5:1。

## 结构和内容

每页仅有一个 `h1`。标题层级不能跳级。
目录列出全部 `h2` 和 `h3`。
目录文字与标题一致，锚点必须有效。
保留现有锚点，避免旧链接失效。

新页面依次包含标题、摘要、资料信息、正文和来源。
摘要只能使用正文已有的事实。
来源说明保留取样时间和适用边界。
旧页面保留事实、引用、外部链接和附件入口。
修正文案时，不增加判断，不删除限制条件。

保留搜索、筛选、双语对照和下载功能。
关闭 JavaScript 后，正文仍可完整阅读。

## 主题、手机和打印

页面支持系统主题、手动亮色和手动暗色。
手动主题不能被系统主题覆盖。
320px 宽度下，页面不能横向溢出。
宽表格和代码块在各自容器内滚动。
图片保持比例，并有有效的替代文字。
键盘焦点必须可见。

打印强制使用亮色，隐藏导航和操作按钮。
打印不得裁掉正文、表格或图片。

## 模板和发布检查

仓库保存统一模板及其样式来源。
页面内嵌统一样式，保留离线阅读能力。
页面特有样式只能服务于内容组件。
页面不得另设正文配色、字体和阅读栏宽度。

`publish.sh reading` 继续负责发布和更新。
发布前递归检查目录中的全部 HTML 页面。
发布检查保留现有 SEO、结构和文案检查。
新增检查验证统一样式和导航规则。
不得通过删除检查或批量豁免完成迁移。

批量迁移仍通过发布脚本写入整理页。
脚本需要支持本地暂存，完成检查后再提交。
本地暂存不得自动推送。
部署流程执行仓库内的统一规范检查。
检查失败时，部署流程不得发布页面。

## 验收

- 80 个现有 HTML 页面通过检查。
- 全部来源链接、附件和原有锚点可追溯。
- 普通报告、旧版指南、双语页和图片页通过截图检查。
- 手机、亮色、暗色和打印模式通过浏览器检查。
- 不符合规范的新页和子页被发布脚本拒绝。
- Hugo 构建通过，原有 SEO 检查通过。

## 主题标签

整理资料使用文章 front matter 的英文主题标签。
每条资料保存 1–5 个标签，名称统一大小写。
资料类型保留原值。列表支持类型或主题筛选。
筛选保留分页与 URL 状态，无脚本时显示全部资料。
发布入口检查标签；批量命令只更新已有条目的标签。
专题子页使用父条目的标签归类。
