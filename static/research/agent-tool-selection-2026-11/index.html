AI Agent 工具选型：手机、多主机与研究写作

比较 Amp、Herdr、Orca、Cindy，以及 Happy、Open WebUI、OpenCode 等高星产品。场景是常出差，手机有 iOS、Android 和鸿蒙 NEXT，办公室和家里有固定的 Mac、Linux，工作以研究、写作、设计为主。

产品调研 · 2026-11-28 · 未做真机与跨境网络测试

主力用 Cindy：任务跑在办公室和家里的固定电脑上，用 iOS 或 Android 手机接手。记忆写成自己的 Markdown 文件放 git，不存在任何一款产品里。鸿蒙 NEXT 没有一款原生支持，只当浏览器副机。Herdr、Orca 等编程调度台不用试；Amp 只在要云端机器、内容不敏感时补位。

结论和配置

选型条件有五条：手机是 iOS、Android 和鸿蒙 NEXT；人常出差；办公室和家里各有固定的 Mac、Linux；工作以研究、写作、设计为主，研发少；记忆要能带走。按这五条筛，答案比较清楚。

  1. 主力用 Cindy。任务跑在办公室和家里的固定电脑上，出差时用 iOS 或 Android 手机接手。这批产品里，只有它把研究、写文件、做 HTML 和远程看桌面放在同一个对话里，也不按代码仓库组织工作。客户端 Apache-2.0，自带模型密钥时免费。[1][2][3]
  2. 记忆写在自己的文件里，放 git。偏好、项目背景、写作规则、技能都写成 Markdown。Amp、Orca、Happy 都读 AGENTS.md 这类指令文件，Cindy 的记忆本身也是 Markdown。换工具时文件跟着走，产品内的记忆只当缓存。[4][5][6][7]
  3. 鸿蒙 NEXT 手机当副机。主要候选都没有原生鸿蒙应用，只能走浏览器。用它看报告、回审批、发短指令，长任务和附件交给另一部手机。[2][8][9][10][11]
  4. 需要“家里电脑关了也能跑”时，加 Amp 当云端补位，只放不敏感的任务。Amp 的线程、工具结果和附件都存在它的服务器上。[12][13]

其余产品不用试。Herdr、Orca、Vibe Kanban、Paradev、Agent Orchestrator 都是给同时写好几路代码的人做的，核心是终端、仓库、worktree 和 PR。研发少的人用不上这些长处，却要承担它们的配置成本。

两个限制要先知道。Cindy 的远程任务在你自己的电脑上执行，电脑休眠或断网，任务就停。Cindy 隐私政策写明数据可能传到中国或其他地区，并提示不要输入商业秘密。公司未公开的材料，用直连模型的方式跑，或者不放进任何一款托管服务。[1][14]

Happy 是备选。它只做一件事：用手机遥控电脑上的 Claude Code 和 Codex，设备之间端到端加密，MIT 开源，免费。如果用下来 Cindy 的手机端不顺手，或者更在意手机到电脑这一段的加密，换 Happy。[11][15]

产品分类

这几款产品经常被放在一起比，其实做的事不同。按“它管什么”分，有五类。

按产品管的东西分类
类别产品它管什么对研究写作的用处
编程调度台Herdr、Orca、Vibe Kanban、Paradev、Agent Orchestrator多个编程 Agent 的终端、worktree、代码审查、PR小。长处都在代码上
编程 AgentAmp、OpenCodeAgent 本身：模型、工具、上下文中。能做网页研究和文件，但界面按写代码设计
手机遥控Happy用手机操作电脑上的 Claude Code、Codex中。管连接，不管资料和交付物
通用工作台Cindy多种 Agent、多台电脑、文件、记忆、技能大。按任务和对话组织，不按仓库
资料库Open WebUI自建服务器上的对话、知识库和检索中。适合长期资料库，不能远程操作电脑

Amp 有点特殊。它有自己的 Agent，也能把 Claude Code 当成模型来用，还卖托管机器。它是这批里唯一闭源、按用量收费的。[16][17]

鸿蒙 NEXT 不能装 Android APK，Android 支持不能算到它头上。在这个前提下，鸿蒙不应该决定选型：所有候选在鸿蒙上的条件都一样差，选谁都只能用浏览器。把它定位成副机，问题就小了。

出差时的连接

各家连回家里电脑的方式不同，出差时差别会放大。

  • Cindy：同账号设备之间远程访问，执行电脑要在线并开启远程访问。文件留在原电脑上，不做整盘同步。[1][25]
  • Happy：经加密中继，或直连。中继看得到连接活动，看不到内容。[28]
  • Herdr：手机用 SSH 直连每台电脑，没有厂商服务器。人在外面要自己配 Tailscale 一类的 VPN。[9]
  • Amp：网页控制自己的 runner，优先 WebRTC，中继作备用；自托管机器也要连 Amp 的控制服务。[29][30]

酒店 Wi-Fi、移动网络、跨境线路和中国大陆访问都没有实测。这一项只能靠试用。

办公室和家里的主机

固定电脑是这套用法的基础。手机只是遥控器，活在电脑上干。

Mac、Linux 主机上的表现
产品主机怎么用要注意的地方
CindyMac、Linux 桌面都能当执行电脑，手机查看和接手任务[2][25]Linux 上只有 Hyprland 能远程看加操作，其他 Wayland 桌面只能看。锁屏和登录前另有限制[31]
HappyLinux 用 systemd，Mac 用 launchd 常驻[32]要自己装和配服务
AmpMac、Linux 跑 runner，也可以用托管机器[29]Linux runner 给的是虚拟桌面，不是你屏幕上那个桌面[29]
Herdr每台电脑跑 herdr-core[33]重启电脑或停掉 core，进程就结束。终端能恢复，任务不会自动续跑[34]
Orca桌面应用，或在 Linux 上用 orca serve 当服务[35]服务的生命周期要自己管

三件事要提前办好：电脑设成不休眠；更新或断电重启后，Agent 能自己起来；磁盘加密照开，不为远程方便关掉它。两台电脑分开用最省心，比如长任务放家里那台，另一台跑独立任务，也当备份。

研究、写作、设计

这部分没有做实测，下面是按功能文档做的判断。

按工作类型选
工作用什么理由
网页研究、写报告Cindy文件、浏览器、HTML 和富内容交付在一个任务里[25]
长期资料库、跨 PDF 检索自己的文件夹；需要时加 Open WebUIOpen WebUI 有知识库检索和导出，但要自管服务器[36]

设计工作要盯住一件事：交回来的是不是可编辑源文件。一张预览图在手机上看着不错，回到电脑上改不了，就等于没交付。

记忆迁移

先拆清楚“记忆”指什么。要带走的有四样：长期记忆（偏好、项目事实、判断）、工作规则（指令、技能、模板）、历史记录（对话和工具结果）、原始材料（PDF、图片、设计源文件）。

各产品能带走什么
产品能带走带不走
Cindy记忆是 Markdown 分片；会话可导出 .cshare，可加密码[7][38]记忆按工作目录和本机账号存，换电脑不会自动跟过去[38]
Amp指令用 AGENTS.md；线程可导出 Markdown 和完整 JSON[4][39]换产品后不能接着跑原来的线程
Orca沿用 CLAUDE.md、AGENTS.md；机器人导入能读人格、记忆、技能[5][40]导入明确不含聊天历史、模型设置和密钥[40]
Happy全局 AGENTS.md、配置文件、本地会话状态[6]没有通用的记忆导出格式
Herdr只管终端，记忆在里面跑的 Agent 那边[33]没有统一的记忆导出
Open WebUI对话 JSON 导入导出；知识库导出 ZIP[41][36]常规导出不带附件；知识库 ZIP 把文件转成纯文本[41]

没有一家能把记忆完整搬到另一家。反过来看，几乎每家都读 AGENTS.md 或 CLAUDE.md 这类文件。所以记忆的正本放在自己手里：

  • 偏好、项目背景、研究结论写成 Markdown，每条带日期、来源和适用范围
  • 事实和推断分开记
  • 附件原件和文字摘要放在一起
  • 整个目录进 git，各个产品只读精简副本

运行中的数据库和凭证目录不要放 Dropbox 同步，冲突了会坏。迁移时用产品自己的导出。验收方法：挑 20 条真实记忆，搬到新电脑上的另一个工具里，随机问 5 条，看来源和范围对不对。

开放程度与商业模式

开源程度和赚钱方式决定了一款产品能用多久，以及停服时你损失多少。

许可证与收费（2026-11-28，美元）
产品开源程度怎么赚钱
Cindy客户端 Apache-2.0；支持技能、插件、MCP[3]自带密钥免费；托管模型服务每月 20 美元起。账号和云能力依赖官方服务[1]
Amp闭源商业许可Hobby 免费，Individual 每月 20 美元起；搜索、图片、语音、机器另按用量扣。机器每小时 0.08 到 2.13 美元[17][42]
OrcaMIT[20]软件免费，卖企业部署和支持，企业价格未公开[43]
HappyMIT，中继可自建[15][28]客户端免费，可选语音订阅[44]
HerdrApp、Core、TUI 都是 Apache-2.0[34]官方称免费，没找到收入来源
Open WebUIv0.6.6 起带品牌条款，不算 OSI 开源[45]保留品牌可免费用，另卖企业许可[45]

Amp 收入最清楚，但锁定最深：闭源，数据在它的服务器上。Herdr 和 Happy 最开放，但 Herdr 没找到收入来源，Happy 只有可选的语音订阅，长期维护没有保障。Cindy 在中间：客户端开源，能离开官方模型服务直连模型，账号和远程连接仍要靠它。

开源客户端不等于能整套自建。Cindy 的云后端、Orca 的 Relay、Amp 的控制服务，都没有确认可以完整自托管。

隐私

数据至少走四段路：手机到电脑、电脑到模型、文件到工具服务、诊断和通知。端到端加密通常只管第一段。只要用云端模型，任务内容就会到模型服务商那里，外壳做得再严也一样。

各家披露的数据路径（厂商自述，未做审计）
产品数据去哪要注意的
Cindy默认存本地；直连模型时不经 XD Gateway；远程和云功能会传内容或元数据[14]政策写明可能传到中国或其他地区，并提示不要输入商业秘密；部分文档预览走云端转换[14]
Amp线程、工具结果、附件存在 Google Cloud 多租户项目；删除后 30 天内清掉[12]声明 SOC 2 Type II。内容最集中在平台上[12]
Happy设备间同步端到端加密；中继能看到连接活动[28]语音会把音频和上下文发给 ElevenLabs，不在加密范围内；丢了恢复密钥，账号找不回来[44][28]
Herdr手机 SSH 直连，厂商不接触终端内容；桌面有可关的匿名统计[46]平台经手最少；VPN 要自己选
Orca配对运行时之间的载荷加密；推送可能带标题和正文[47]企业页写的是 SOC 2 Readiness，和 Type II 不是一回事[43]
Open WebUI服务器、数据库、模型端点都在自己手里[48]存储加密要自己配；服务器被攻破就全没了[48]

按隐私排，Herdr 和 Happy 平台经手最少，Amp 最多。Cindy 在本地这一段做得好，但那条跨境条款对处理公司材料是实打实的约束，要按任务分开：公开资料随便用，未公开的材料走直连模型。

试用方法

只试 Cindy，Happy 留作对照。用一周，做三件事：

  1. 出差前把家里电脑设成不休眠，人在外面发一个长研究任务。中途切 Wi-Fi 和移动网络、锁屏再回来，看任务有没有断，附件和草稿在不在。
  2. 用鸿蒙手机的浏览器打开结果，看能不能读完报告、下载文件。读不了，就确认它只当通知机。
  3. 把规则和记忆文件交给第二个工具（Happy 或 Claude Code），问 5 个只有记忆里才有答案的问题。

第一件做不到，就换 Happy 再测一遍。三件都过，就不用再看别的产品。
