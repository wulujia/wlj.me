采购调研 / 2026-10-26

深圳及珠三角墨水屏设备采购调研

采购 8—10 台设备，开发定制功能，验证 Agent 与联网产品。

价格与库存取样于 2026 年 10 月 26 日，发布时未重新询价。
调研日期：2026 年 10 月 26 日。范围：设备、开发套件与制造合作。

采购建议

优先联系 Seeed Studio（矽递科技）。它在深圳，销售带外壳的墨水屏设备，也提供开发套件。现有产品允许开发者烧录自己的固件。小批量可以从标准商品采购开始。

采购建议

桌面信息终端优先购买 reTerminal E1001。需要触控时，先测试 reTerminal E1003。需要 Android 应用时，选择广州 BOOX 的 Go 7。需要直接测试蜂窝网络时，选择 BOOX Palma 2 Pro，或深圳 LILYGO 的 T-Deck Pro 4G。

这些建议有一个限制：公开证据没有证明任何单一型号，同时满足“开放开发、可靠性经过验证、用户评价好、出货量大、内置 eSIM”全部条件。这里的产品值得购买做开发测试。它们还不能直接作为量产方案。

本次把“开发套件”理解为两类：可烧录固件的硬件套件，以及配有官方 SDK 的成品设备。两类分别标明。若要求开放主板、操作系统和底层驱动，BOOX 的公开应用 SDK 不够。

本次按公司或服务机构所在地筛选。工厂所在地、生产资质和自制比例仍需核实。表中多数公司提供设备设计、组装或开发硬件，并不生产电子墨水材料。

值得购买的设备

1. Seeed reTerminal E1001：桌面 Agent 信息终端首选

这是带外壳、电池和支架的设备。官方商品页本次显示 US$69，有货。页面显示 42 条评价，评分为 91.83%。这是卖家网站的评价样本，不能代表全体用户。官方商品页

它采用 7.5 英寸黑白屏，分辨率为 800 × 480。它没有触控。ESP32-S3 配有 8 MB PSRAM。设备支持 Wi-Fi 和蓝牙，电池容量为 2000 mAh。官方列有 UART、I²C、GPIO 扩展接口。系列规格

开发者可以使用 Arduino 和显示库，烧录自己的界面。官方教程包含文字、图形、图片和灰度示例。开发流程不要求使用厂商云平台。官方开发教程

建议用途：日程、任务、提醒、Agent 结果卡片。服务器运行 Agent，设备接收结果。设备也可以接受按键输入。ESP32 的资源不适合直接运行常见的完整 Python／Node.js Agent 环境，更不适合本地运行通用大语言模型。这是根据处理器与内存作出的工程判断。

CNX Software 拆机并测试了该设备。测试覆盖 SenseCraft 与 Home Assistant。评测认为黑白型号刷新更快，低频更新更有利于续航。样品由 Seeed 提供，因此这项测试不能替代独立采购后的可靠性测试。评测原文

购买前需确认：10 台是否使用相同屏幕与主板版本；是否提供对应的生产固件；麦克风在该批次是否安装并开放。官方不同文档对麦克风的表述不一致。首轮方案应按实际样机测试结果开发。

2. Seeed TRMNL 7.5" (OG) DIY Kit：用于开发自有外形

套件包含 800 × 480 黑白屏、XIAO ESP32-S3 Plus 驱动板、2000 mAh 电池和延长排线。本次商品页显示 US$47.99，有货，10 台档位也是 US$47.99。页面显示 67 条评价，评分为 92.46%。官方商品页

它适合测试自己的外壳和布局。它与 E1001 的差别主要在交付形态。购买时应核对包装是否包含外壳。官方最初发布的套件没有外壳，并提供外壳参考设计。官方发布说明

TRMNL 的名称不代表必须购买其云服务。自有固件可以使用自己的服务器。若使用 TRMNL 的服务，则需单独核对设备许可与服务费用。开发原型时，应直接保存自己的固件与服务接口。

本次没有找到该型号可核实的累计出货量。67 条评价只能说明存在用户反馈。

3. BOOX Go 7：Android 应用开发首选

Go 7 使用 7 英寸 Carta 1300 黑白屏。它配有 4 GB 内存、64 GB 存储和 Android 13。设备有前光，支持安装 Android 应用。它没有内置蜂窝网络。官方规格与商品页

本次官方商品数据列出：香港仓标准套装 US$249.99，美国仓 US$269.99。对应选项显示可购买。仓库价格与配送地区有关，不能当作深圳交货报价。

BOOX 提供官方 Android SDK 示例。示例覆盖墨水屏刷新、前光、手写和屏保等功能。官方 SDK 仓库

它适合先验证自己的 Android 应用。例如，应用接收用户输入，再调用服务器上的 Agent。若需要本地运行少量任务调度，也应使用 Android 支持的运行方式。现有桌面 Agent 程序能否直接运行，需要单独测试。

TechRadar 给 Go 7 的整体评价为 4／5。评测肯定屏幕，也指出界面学习成本和电池消耗。评测原文

应用 SDK 不包含系统签名授权或主板设计。默认启动自有桌面、设备锁定、后台常驻、静默安装和系统升级控制，都应逐项验证。官方仓库中仍有依赖下载与设备兼容问题的报告。SDK 问题记录

4. BOOX Palma 2 Pro：成品蜂窝联网测试首选

它采用 6.13 英寸 Kaleido 3 彩色屏。它配有 8 GB 内存、128 GB 存储和 Android 15。官方列有蜂窝数据功能和混合 SIM 卡槽。本次官方商品数据列出：香港仓标准套装 US$379.99，美国仓 US$399.99，均显示可购买。官方商品页

它适合验证便携 Agent 的界面与联网流程。它比开发板更接近用户使用的成品。不过，公开资料未证实它提供原生内置 eSIM。采购时应按实体 SIM 方案安排测试。官方把 SIM 功能定位为数据连接，语音通话不应列为已确认能力。

TechRadar 测试肯定了 Android 应用表现，也指出彩色屏底色更暗，文字表现和价格存在取舍。评测原文

若产品只需要文字卡片，彩色屏未必能提高使用体验。若蜂窝网络是首轮必须验证的功能，Palma 2 Pro 比 Go 7 更方便。它的硬件定制权限仍需单独商谈。

5. LILYGO T-Deck Pro 4G：开放蜂窝硬件实验

必须选择 A7682E 4G 版本。PCM5102A 版本的功能不同。设备使用 ESP32-S3，配有 3.1 英寸、320 × 240 墨水屏，以及实体键盘。官方列有 Wi-Fi、蓝牙、LoRa、GPS 和 1400 mAh 电池。官方商品页

本次官方商品数据中，中国仓 A7682E 普通天线版本为 US$94.68，显示可购买。部分其他仓库与预装固件选项不可购买。商品数据没有证明同一选项能立即交付 10 台。

它适合验证“键盘输入→蜂窝上传→Agent 返回→屏幕显示”的完整流程。屏幕分辨率较低，长文本和复杂界面需要分页。它仍是开发设备，应用功能需要自行开发。

开发资料从商品页的技术支持入口进入。采购时应要求厂商固定源码版本，并提供该批硬件的烧录示例。

A7682E 是 LTE Cat 1 模组。官方列出的 LTE-FDD 频段为 B1／B3／B5／B7／B8／B20。该模组没有覆盖所有地区的全部频段。中国与新加坡测试需使用目标运营商的实际 SIM 卡验证。SIMCom 官方规格

它没有经过本次调研确认的内置 eSIM。LoRa 也不能直接代替蜂窝互联网。该型号缺少可核实的大规模出货数据，因此只建议先买 1—2 台。

6. Waveshare 7.5inch e-Paper HAT：Linux 原型与硬件扩展

这是一套屏幕与驱动板，主机需另购。官方列出的黑白屏为 800 × 480。页面标价为 US$56.99，另列有数量价格。官方提供 Raspberry Pi、Arduino、STM32 等示例。官方商品页

若希望运行现有 Python 或 Node.js Agent，可配 Linux 主机。若需要蜂窝网络，再连接兼容的蜂窝模组。这样更接近普通软件开发环境。代价是外壳、电源、启动时间和续航需要自行处理。

微雪也销售 ESP32-S3-SIM7670G-4G 开发板。官方页面列价 US$48.99。该板可用于测试 4G，再接适配的显示屏。它本身不包含本报告推荐的 7.5 英寸屏。蜂窝开发板

屏幕版本必须固定。官方区分 V1、V2，以及不同销售时间对应的程序。不能只凭“7.5 英寸”选择驱动。采购清单应写明屏幕版本与对应程序。官方版本说明

本次没有核实该型号的累计出货量与统一用户评分。公开驱动和长期销售记录可以降低开发风险，不能证明每台设备的质量。

暂不作为首批主力的厂家与型号

M5Stack：开放程度好，需先解决供货与稳定性问题

PaperS3 的官方商品页明确标注 EOL，表示产品生命周期结束。它有用户好评，页面有 24 条评价，但不适合开始一个依赖后续补货的项目。PaperS3 官方状态

PaperMono 是新的替代候选。它有 3.97 英寸触控黑白屏、前光、Wi-Fi，部分版本含 NFC 与 LoRa。不过，官方文档明确提示 M5GFX 中的屏幕驱动波形不稳定，并建议使用屏幕厂商的 OTP 示例。文档还列出充电芯片相关的 I²C 稳定性注意事项。PaperMono 官方文档

建议只购买 1 台作触控产品比较。先确认厂商建议的固件路径，再做长时间测试。暂不建议按“稳定可靠”的前提购买 10 台。

Elecrow：低成本开发备选

CrowPanel 4.2 英寸 E-Paper 有 400 × 300 黑白屏。主控是 ESP32-S3，配有按键、旋钮、扩展接口和亚克力保护结构。官方提供 Arduino 等开发资源，以及原理图与 PCB 文件。官方文档

文档同时提供 V1.0 与 V1.2 显示程序。文档提示：一个程序无法点亮屏幕时，尝试另一个程序。采购时必须要求同一批次。官方代码库可以用于核对资料完整性。官方代码库

本次没有取得稳定的直销报价，也没有找到足够的型号级销量与评价数据。它可以进入报价比较，采购优先级低于 Seeed。

LILYGO T5 E-Paper S3 Pro：用户评价不支持优先推荐

本次官方页面显示 3.25／5，共 12 条评价。部分低分涉及固件支持与用户预期，也有功耗反馈。这些评价不能全部归为硬件故障，但不支持把它列为“用户评价好”的首选。官方商品与评价

SEEKINK：适合后续制造合作

SEEKINK 在深圳有服务机构，总部和制造主体在江西。官网明确提供样品与演示套件。它也提供模组、带控制板的套件和 OEM／ODM 服务。官方联系页、产品合作方式

官网标准 MOQ 分别列为：TAG 1000 台、Harmo 500 台、SHINE 100 台、EPD 模组 3000 片。它允许按项目调整，但这不构成接收 8—10 台订单的承诺。官方 FAQ

建议在确定屏幕、外形和联网方案后联系。询价应明确要求“10 台标准样机＋开发资料”。报价中需单列开发费与后续量产 MOQ。

Bigme、Good Display 与大批量电子价签厂家

Bigme 的官方联系地址在深圳。它有多类成品设备，但本次没有核实官方公开 SDK 及对应开发套件。仅能安装 Android 应用，不能证明厂商开放屏幕底层控制。Bigme 官方联系页

Good Display／佳显有屏幕和开发套件。不过，其官方主体在大连，不符合本次地区首选。它可以作为区域外的屏幕供应商备选。佳显官网

电子价签的大批量出货不代表适合 Agent 设备。采购前必须核对：能否烧录自有程序、是否开放无线协议、是否依赖基站，以及是否能直接联网。没有这些资料，不应因出货量大就购买。

“稳定、好评、出货量大”的证据

这三个条件需要分别证明。认证资料不等于现场故障率。用户评分不等于销量。公司的总销量也不等于所选型号的销量。

BOOX 的规模证据相对较强。公开报道根据其申报资料指出：2024 年生产力平板销量为 21.6 万台。这个数字仅涵盖一类产品，不能当作 Go 7 或 Palma 2 Pro 的销量。《每日经济新闻》报道、销量数字报道

本次没有直接复核完整申报文件，因此该数字按媒体转述处理。其余开发设备没有足够公开资料证明“出货量大”。本报告没有把它们标为已满足这一条件。

厂商提供的产能也不能作为出货量。例如，SEEKINK 公布了产线与产能信息。这只能用于安排供应商调查，不能证明某一款设备的销量。

Agent 与 eSIM 的开发边界

先确定 Agent 在哪里运行

实际功能 适合的平台 对设备的影响
显示 Agent 整理的日程、提醒与摘要 ESP32＋服务器 开发简单；便于休眠；依赖网络
输入问题、接收结果、保存少量状态 ESP32＋服务器，或 Android 需设计按键、键盘、触控或语音输入
在设备运行 Android 应用与任务逻辑 BOOX 自有应用可开发；后台权限需验证
运行现有 Python／Node.js 程序 Linux 主机＋墨水屏 软件迁移更直接；电源与结构需开发
在设备离线运行大语言模型 另选算力平台并测试 本轮推荐设备没有可交付性能证据

这些是平台选择建议。设备参数不能替代实际 Agent 的测试结果。

对于首轮产品，建议让服务器完成模型调用和工具执行。设备保存最后一份可读结果。网络中断时，屏幕显示数据时间。用户需要立即响应的操作，应先显示接收状态，再等待结果。

文字应按句子或卡片更新。逐字刷新会增加闪烁和残影。不同屏幕的局部刷新能力差异很大。应使用该型号支持的刷新方式。

内置 eSIM 需要单独验证

本轮主推设备没有已核实的原生内置 eSIM。T-Deck Pro 和 Palma 2 Pro 的实体 SIM 方案，可以先验证蜂窝联网需求。若“出厂内置 eSIM”是硬条件，则需定制或寻找另一个已确认的型号。

eSIM 方案需要兼容的蜂窝模组、eUICC，以及号码配置下载与管理方式。GSMA 的 IoT 架构包含设备侧配置助手与远程管理组件。实际方案由模组、eUICC 和连接服务商共同决定。GSMA 架构说明

Quectel 的 EG915U 官方资料列有 eSIM 应用说明。它可以作为定制模组调查对象。不能据此认定任何 EG915U 开发板都包含 eUICC，或已开放相关固件功能。Quectel 官方资料

向供应商索取以下结果：

  1. 提供模组与 eUICC 的完整型号。
  2. 提供对应固件与开发说明。
  3. 演示首次联网与号码配置下载。
  4. 演示切换连接服务商后的联网。
  5. 提供中国与新加坡的实测记录。
  6. 单列流量、管理平台和号码配置费用。

设备静态显示省电，不能保证联网整机省电。持续收听语音、保持蜂窝在线和频繁更新，都需要单独测量。标称几个月续航通常不适用于持续交互的 Agent。
